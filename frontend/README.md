# Ambulans Yönetimi V1 Frontend

Mobil-first React/Vite arayüzü.

## Çalıştırma
1. Node.js 20+ kurulu olmalı.
2. `npm install`
3. `.env.example` dosyasını `.env` olarak kopyalayın.
4. Backend adresini `VITE_API_URL` ile ayarlayın.
5. `npm run dev`

## Hazır ekranlar
- Kurumsal giriş
- Analiz dashboard
- Araç listesi ve arama
- Araç detay kartı
- Arıza & İş Emri iskeleti
- Uyarılar Merkezi
- Modül menüsü
- Mobil alt navigasyon

Backend çalışmıyorken tasarım incelemesi için örnek araç verileri görünür.
